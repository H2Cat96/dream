# 小羊 Agent 入口设计

## 目标
为当前 app 增加一个在所有页面固定可见的“小羊宠物入口”，用户点击后可以通过文字或语音与小羊沟通。

## 设计结论
- 小羊入口固定显示在所有页面右侧。
- 小羊入口默认半露出，带轻微漂浮动效，气质偏“调皮朋友型”。
- 点击小羊后，从右侧滑出半高聊天抽屉。
- 抽屉不做全屏覆盖，保留当前页面内容的可见性。
- 抽屉支持双入口：文字输入和按住说话。

## 交互结构
### 1. 固定宠物入口
- 位置：页面右侧中下部，避开底部导航。
- 形态：圆润挂件式按钮，带小羊形象。
- 状态：默认轻微呼吸/漂浮；点击时有轻微缩放反馈。

### 2. 聊天抽屉
- 方向：从右向左滑出。
- 高度：半高，视觉上像一块贴在页面上的梦境玻璃卡片。
- 关闭：点击遮罩、点击关闭按钮。

### 3. 抽屉内容
- 顶部：小羊头像、名字、一句调皮陪伴文案。
- 中部：2-3 条假的聊天记录，用于演示“它会回应”。
- 底部：
  - 一个“按住说话”按钮
  - 一个文字输入框
  - 一个发送按钮

## 视觉方向
- 与当前产品保持一致：梦境玻璃感、深色氛围、柔和高光。
- 小羊本体更童趣、更活泼，不做写实。
- 抽屉采用黑色玻璃底，边缘带浅色描边和轻微发光。

## 实现范围
本轮只做高保真假交互：
- 小羊入口始终显示
- 抽屉可打开/关闭
- 语音按钮和输入框可点击
- 假聊天内容可展示
- 不接真实 agent 服务

## 验收标准
- 所有页面都能看到小羊入口。
- 小羊入口不会遮挡底部导航主按钮。
- 点击小羊后，抽屉稳定出现在手机框内部。
- 抽屉同时具备文字和语音入口。
- 整体风格与现有梦境产品一致，不突兀。
